# Assessment Frontend (React)

This is the frontend application for the Assessment Summary project.

It provides a mobile-first interface for viewing assessments and managing hazards.

## Tech Stack

- React
- TypeScript
- Vite
- Zustand (state management)
- React Router

---

# Features

- Assessment list page
- Assessment summary page
- Hazard list
- Add hazard
- Delete hazard
- Edit assessment
- Form validation matching backend validation
- Reusable modal component
- Mobile-first layout
- Not Found page for invalid routes

---

# Setup Instructions

### Run

## Manual Installation
* Download and setup the local development environment by cloning the git repository and installing the NPM packages:
    ```shell script
    npm install
    ```

* Create your own environment file.
    ```shell script
    cp .env.dist .env
    ```
* Run development server
    npm run dev
